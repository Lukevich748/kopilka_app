# 🐷 Копилка

Приложение для учёта мультивалютных накоплений: добавляйте пополнения и
снятия в любой валюте, следите за общей суммой (с пересчётом в выбранную
валюту) и смотрите всю историю операций.

## Функциональность

- ➕➖ Пополнение и снятие в USD, EUR, PLN, RUB и BYN — снять можно не больше, чем реально лежит в этой валюте
- ⚙️ Настройки — включение/отключение валют из справочника
- 💰 «Всего накоплено» — сводный итог с пересчётом в выбранную базовую валюту + разбивка по каждой валюте, с анимацией «барабана» при изменении суммы
- 💱 Блок «Курсы валют» с живым курсом (обновляется автоматически и по кнопке) — карточку можно перевернуть и задать свой номинал показа курса для каждой валюты (например, «10 RUB» вместо «1 RUB»)
- 🕘 Полная история операций с датой, редактированием и удалением записи (с подтверждением перед удалением)
- 📈 График динамики накоплений по месяцам (нарастающий итог) с наведением на точку
- 👁️ Скрытие сумм по кнопке-глазику (приватность при чужих взглядах) — выбор запоминается в браузере
- 🔒 Вход по логину и паролю — при первом запуске сама форма входа предлагает зарегистрироваться
- 🎨 Современный дизайн: тёмная тема, glassmorphism, анимированный градиентный фон, плавные анимации

Данные хранятся в базе Supabase (Postgres) — см. раздел «Развёртывание» ниже.

## Как запустить на своём компьютере

Требуется установленный [Node.js](https://nodejs.org/) версии 18 или выше и проект в [Supabase](https://supabase.com/) (см. «Развёртывание»).

```bash
# 1. Перейти в папку проекта
cd kopilka_app

# 2. Установить зависимости
npm install

# 3. Задать переменные окружения (см. .env.example)
cp .env.example .env
# и вписать в .env свои SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY

# 4. Запустить сервер
npm start
```

После этого откройте в браузере **http://localhost:3000** — приложение готово к работе.

Для остановки сервера нажмите `Ctrl+C` в терминале.

## Развёртывание (Vercel + Supabase)

Приложение — serverless-функция (Express в `server/app.js`, точка входа для
Vercel — `api/index.js`) плюс статика из `public/`. Хранение данных — в
Supabase, потому что файловая система serverless-функций не сохраняется
между вызовами.

1. **Supabase.** Создайте проект на [supabase.com](https://supabase.com/).
   В разделе *SQL Editor* выполните `supabase/schema.sql` из этого репозитория —
   он создаст таблицы `settings`, `transactions`, `users` и `sessions`. В
   *Project Settings → API* возьмите `Project URL` и `service_role` ключ
   (не `anon`!).
2. **Vercel.** Импортируйте репозиторий на [vercel.com](https://vercel.com/).
   В *Project Settings → Environment Variables* добавьте:
   - `SUPABASE_URL` — Project URL из Supabase
   - `SUPABASE_SERVICE_ROLE_KEY` — service_role-ключ из Supabase

   Framework Preset можно оставить «Other» — конфигурация в `vercel.json`
   уже направляет запросы `/api/*` в serverless-функцию `api/index.js`, а
   остальное отдаётся статикой из `public/`.
3. Задеплойте — приложение должно заработать по выданному Vercel домену.

`service_role`-ключ обходит Row Level Security и обращается к базе только
из серверного кода — в браузер он не попадает, поэтому держите его только в
переменных окружения (никогда не коммитьте в репозиторий).

## Вход по логину и паролю

Всё приложение (и весь API, кроме самого входа) закрыто за экраном входа.
Никаких дополнительных переменных окружения не нужно — регистрация проходит
прямо в приложении:

- Пока в базе нет ни одного аккаунта, экран входа сам показывает форму
  регистрации — впишите любой логин и пароль (от 6 символов) и нажмите
  «Зарегистрироваться».
- После этого регистрация закрывается (проверяется, что аккаунт всего один
  — приложение личное), и та же форма становится обычным входом.
- Пароль хранится в Supabase только как bcrypt-хеш. Сессия — случайный
  токен в httpOnly-куке (30 дней), сама сессия и её срок годности хранятся
  в таблице `sessions`. Выйти можно кнопкой «Выйти» в Настройках.

Если нужно сбросить доступ (забыли пароль) — удалите строку из таблицы
`users` в Supabase (Table Editor) и зарегистрируйтесь заново.

## Технологии

- Backend: Node.js + Express, хранение данных в Supabase (Postgres)
- Frontend: чистый HTML/CSS/JS без сборщиков — открывается мгновенно, не требует интернета

## Курсы валют

Курс подтягивается автоматически из открытого API [Frankfurter](https://www.frankfurter.app/)
(данные Европейского центробанка) — обновляется по мере необходимости (если
сохранённому курсу больше 6 часов, он подтянется заново при следующем
запросе), плюс по кнопке «↻» в блоке «Курсы валют». Для этого серверу нужен
доступ в интернет. Если сети нет или сервис недоступен, приложение не падает, а
использует приблизительный резервный курс (видно по надписи под курсами) —
его при желании можно поправить в `server/rates.js` (`FALLBACK_RATES_TO_USD`).
Frankfurter не публикует курс для RUB и BYN — для них всегда используется
резервное значение, это не баг.

## Настройки

Шестерёнка в шапке открывает панель настроек. Пока в ней один раздел — «Валюты
и курсы»: список всех валют из справочника с переключателями, каких из них
использовать. Отключённую валюту нельзя выбрать для новой записи, но старые
записи в ней остаются видимыми и редактируемыми. Нельзя отключить валюту,
выбранную как базовая, или последнюю оставшуюся включённую валюту.
