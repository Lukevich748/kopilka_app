# 🐷 Копилка

Приложение для учёта мультивалютных накоплений: добавляйте пополнения в любой
валюте, следите за общей суммой (с пересчётом в выбранную валюту) и смотрите
всю историю пополнений.

## Функциональность

- ➕ Добавление накоплений в разных валютах (USD, EUR, RUB, GBP, UAH, KZT, CNY, JPY, CHF, TRY, AUD, GEL)
- 💰 «Всего накоплено» — сводный итог с пересчётом в выбранную базовую валюту + разбивка по каждой валюте
- 🕘 Полная история пополнений с датой, комментарием и возможностью удаления записи
- 🎨 Современный дизайн: тёмная тема, glassmorphism, анимированный градиентный фон, плавные анимации

Данные хранятся локально в файле `data/db.json` — никуда не отправляются.

## Как запустить на своём компьютере

Требуется установленный [Node.js](https://nodejs.org/) версии 18 или выше.

```bash
# 1. Перейти в папку проекта
cd kopilka_app

# 2. Установить зависимости
npm install

# 3. Запустить сервер
npm start
```

После этого откройте в браузере **http://localhost:3000** — приложение готово к работе.

Для остановки сервера нажмите `Ctrl+C` в терминале.

## Технологии

- Backend: Node.js + Express, хранение данных в JSON-файле (без внешних БД и нативных зависимостей — работает «из коробки» на любой машине)
- Frontend: чистый HTML/CSS/JS без сборщиков — открывается мгновенно, не требует интернета

## Курсы валют

Курс для пересчёта общей суммы в единую валюту — приблизительный и зашит в
`server/currencies.js`. При желании его можно поправить вручную под актуальный курс.
